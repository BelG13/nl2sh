# 🧠 nl2sh — Natural Language to Shell

`nl2sh` is a local command-line tool that lets you write natural language instructions and get validated shell commands generated by a small language model — **entirely offline**.
It’s built with **Transformers**, **FastAPI**, and your a fine-tuned **Qwen2.5-0.5B-Instruct**.

---

## 🚀 Overview

The goal of `nl2sh` is simple:
👉 Type what you want to do in natural language,
👉 Get the corresponding shell command,
👉 Confirm or reject it interactively.

All processing happens **locally** — no external API calls, no data sent to the cloud.

### ✨ Key Features
- 🧩 **Local execution only** — your commands and data never leave your machine.
- ⚡ **Fast and lightweight** — powered by the compact Qwen2.5-0.5B-Instruct model.
- 🔍 **Interactive validation** — approve or reject each generated command before execution.
- 🧠 **Custom fine-tuned model** — trained on the [`nl2bash` dataset](https://github.com/TellinaTool/nl2bash).
- 🐍 **Built with Python, Transformers, and FastAPI**.

## 💻 Usage

Once installed, you can launch the CLI directly from your terminal:

```bash
nl2sh
````

Then simply type a natural language instruction, for example:

```
> list all files bigger than 100MB
```

The model will generate a command such as:

```
find . -type f -size +100M
```

You can then **validate** or **reject** the command interactively.

### Controls

* Press **Enter** to submit your instruction.
* Press **Ctrl + C** or just hit **Enter** on an empty line to quit.

## 🔒 Privacy & Locality

`nl2sh` is designed with **privacy by default**.
Every inference, validation, and command generation happens locally — ensuring your instructions, history, and shell context are never uploaded or logged remotely.
